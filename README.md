## Projects

### 01. Brightcart Customer Conversion Prediction

A binary classification project that predicts whether a website visitor will convert to a purchase.

**Techniques covered:**
- Data cleaning
- Data merging
- Feature engineering
- One-hot encoding
- Min-Max normalization
- Classification model comparison
- Model evaluation
- Business interpretation

**Best model:** Tuned AdaBoost  
**Accuracy:** 77.33%  
**F1-score:** 65.31%
